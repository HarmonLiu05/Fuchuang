🦍 大猩猩个体识别系统

基于 ResNet50 + ArcFace 的深度学习模型

📋 系统概览

本系统使用深度学习技术，通过大猩猩面部图像自动识别个体身份。适用于野生动物监测、行为研究等场景。

ResNet50 (ImageNet 预训练)
特征维度
2048 → 512 (瓶颈层压缩)
损失函数
ArcFace (角度空间边际)
训练设备
RTX 4050 (6GB 显存)
数据集
Chimpanzee Faces (C-Zoo)
个体数量
24 个大猩猩个体

📷

112 × 112 × 3 RGB 图像

为什么使用 512 维瓶颈层？

ResNet50 原始输出为 2048 维，但通过 512 维瓶颈层可以：

  • 压缩特征：512 维是人脸识别领域验证的最优特征维度
  • 防止过拟合：小样本任务下 2048 维过于稀疏
  • 加速检索：便于后续使用 Faiss/Milvus 进行快速相似度搜索

为什么使用 ArcFace？

ArcFace 在角度空间添加边际 (θ + m)，使得：

  • 类内更紧凑：同一个体的特征聚集在一起
  • 类间更分离：不同个体的特征分得更开
  • 更好泛化：对未见过的样本也能准确识别

🔄 训练流程

1

数据准备

  • 加载 2109 张图片
  • 按 80/20 划分训练/验证集
  • 训练集增强：翻转、仿射、颜色抖动、高斯模糊、随机擦除
2

混合精度训练

  • batch_size=4, 梯度累积 8 步
  • FP16 混合精度节省显存
  • Adam 优化器 + 余弦退火 LR
  • Label Smoothing (0.1) 防止过拟合
3

分阶段训练

  • 阶段 1 (Epoch 1-10)：冻结 backbone 前 3 层
  • 阶段 2 (Epoch 11-30)：解冻全部微调
  • 每 epoch 保存最佳模型

训练阶段对比

训练：layer4 + bottleneck + arcface

📊 评估流程

1

特征提取

  • 模型设为 eval 模式 (关闭 Dropout)
  • 遍历验证集所有图片
  • 通过 backbone + bottleneck 提取 512 维特征
  • 所有特征进行 L2 归一化
2

相似度计算

  • 计算特征矩阵的余弦相似度 (N × N)
  • 排除对角线 (避免样本与自己比较)
  • 为每个样本找到最近邻的样本
  • 比较最近邻的真实标签
3

指标计算

  • Accuracy：最近邻标签一致的样本比例
  • TAR@FAR：在不同阈值下的真假阳性率
  • Threshold：FAR=0.1% 时的最佳相似度阈值

python inference.py --checkpoint checkpoints/best_model.pth --image chimp.jpg --open_set --threshold 0.5
